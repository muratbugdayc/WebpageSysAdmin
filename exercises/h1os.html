Practical 1 — Identify core components

  • In one line: what is an address space?
  • List 4 subsystems/services you expect on enterprise z/OS (JES2, TCP/IP, RACF…).
  • Explain what spool is used for in batch.
Reveal expected answer shape
  • Address space: isolated virtual memory environment for running work.
  • Subsystem examples: JES2/JES3, TCP/IP, RACF, WLM, SDSF, CICS/Db2/IMS.
  • Spool: disk queue for job input/output and print data, enabling scheduling and reliable output handling.

Practical 2 — Legacy workflow (TSO/ISPF)

  • Describe going to ISPF 3.4 and listing datasets under your HLQ.
  • SOLUTION click to show/hide 
    
CREATE TABLE CUSTOMER (
  CUST_ID INTEGER NOT NULL,
  NAME VARCHAR(50) NOT NULL,
  EMAIL VARCHAR(100),
  CONSTRAINT PK_CUST PRIMARY KEY (CUST_ID)
);

CREATE TABLE "ORDER" (
  ORDER_ID INTEGER NOT NULL,
  CUST_ID INTEGER NOT NULL,
  ORDER_DATE DATE,
  CONSTRAINT PK_ORDER PRIMARY KEY (ORDER_ID),
  CONSTRAINT FK_CUST FOREIGN KEY (CUST_ID)
    REFERENCES CUSTOMER (CUST_ID)
    ON DELETE RESTRICT
);
    Explanation: Primary keys uniquely identify rows. Foreign keys enforce referential integrity. ON DELETE RESTRICT prevents deleting a customer that has orders.
